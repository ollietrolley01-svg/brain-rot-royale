## LESSONS (four)
1. A probe reads Studio's Source with CRLF: a needle never contains a line ending or leading tab; match the statement, replace with a harmless statement.
2. A planted fault must travel the real route and not depend on the model: plant your own block (a Ball has no flat face; nudging the PrimaryPart moves everything; a Sphere-shaped "Seam" is a sliver).
3. A private copy goes stale under other landings: land with an anchored script re-derived from the current file (--check counts anchors), never a file copy; measure only on a snapshot built after the edit.
4. A tolerance is in the model's own units: the guns are built in millimetres (0.0038 studs/mm) and the pass is 0.92 mm, so "18 → 18.4" moved a face 0.2 mm — read the builder's scale before choosing a step, then MEASURE the landed tree, not the intent.
